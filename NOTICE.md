# Data attribution and implementation scope

SECOM: Michael McCann and Adrian Johnston (2008), UCI Machine Learning Repository.
DOI: https://doi.org/10.24432/C54305
Dataset license: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/

The original source is downloaded from https://archive.ics.uci.edu/static/public/179/secom.zip.
Recorded source hashes are in results/protocol.json. The measurement matrix has 590 columns.
Derived data recodes pass=-1/fail=+1 to normal=0/defect=1 and assigns anonymous sensor_000..sensor_589 names.
Figures, sample measurements and prediction tables derive from that public dataset and are not company data.

The dataset license does not automatically license this project's source code.
No separate open-source code license has been selected. Publication alone does not grant such a license.
This is an AI-assisted implementation. It is not affiliated with a semiconductor manufacturer and is not approved for production quality decisions.
